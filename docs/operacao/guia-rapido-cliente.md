## 2. Fluxo do dia

```
Manhã/tarde          →  Cadastrar entregas
Durante o dia        →  Executar rota (Planejador)
Pendências           →  Registrar valores em aberto
Fim do dia           →  Gerar prestação de contas
Semana/mês           →  Consultar relatórios
```

---

## 3. Nova entrega

**Menu:** Entregas → **Nova entrega**

| Campo | Obrigatório |
|-------|-------------|
| Endereço | Sim |
| Bairro | Sim |
| Valor | Sim |
| Nome do cliente | Não |
| Pago pelo cliente | Marcar se o cliente pagou direto ao motoboy |

---

## 4. Pendência

**Menu:** Pendências → **Nova pendência** _(somente Admin)_

Registre valores a receber. Marque **Recebido** quando quitar. Pendências abertas entram no desconto da prestação do dia.

---

## 5. Prestação do dia

**Menu:** Prestação _(somente Admin)_

1. Confirme a **data**
2. Revise a **prévia**
3. Clique **Gerar Prestação do Dia**
4. **Copiar texto** ou **Enviar no WhatsApp**
5. **Exportar PDF** se precisar de arquivo

> Gere a prestação **todo dia** para os relatórios ficarem corretos.

---

## 6. Relatórios

**Menu:** Relatórios _(somente Admin)_

Filtre por **semana** ou **mês**. Use **Exportar PDF** para o contador.

---

## 7. Planejador de rotas

**Menu:** Planejador de Rotas

1. Confirme o **endereço de partida**
2. Adicione as entregas do dia
3. **Calcular melhor rota**
4. Durante a entrega, atualize o **status** de cada parada
5. Envie o andamento pelo **WhatsApp** se precisar

---

## 8. Instalar no celular

- **Android:** toque em **Instalar app** quando aparecer o aviso
- **iPhone:** **Compartilhar** → **Adicionar à Tela de Início**
